### Convention: document structure
1. Front matter (id, title, agent, date, clauses, status).
2. `# <Title>` then a one-paragraph *Scope* naming the element, its boundary and the responsible clauses.
3. `## Assumptions` — for SEooC every assumption is an item (`### AOU-nnn`) so it can flow into the safety manual.
4. `## Items` — the traceable items in id order.
5. `## Open points` — the list of all PENDING markers in the document, one line each.
Normative text is cited by clause id, never copied. House wording: "shall" for requirements, "should" for recommendations.
